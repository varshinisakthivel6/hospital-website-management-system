# 🏥 Hospital Website Management System

## 📌 Project Overview
Developed a responsive hospital website using HTML, CSS, JavaScript, PHP, and MySQL to provide hospital information and patient services. The application supports patient registration, login, appointment booking, and patient record management.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XML
- XAMPP

## ✨ Features
- Responsive hospital home page
- Patient registration and login
- Hospital services catalogue and cart
- Appointment booking
- JavaScript form validation
- Patient record management using CRUD operations
- Patient image upload and display
- MySQL database connectivity
- XML-based hospital information

## ⚙️ How to Run
1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs\`.
3. Start Apache and MySQL.
4. Open `http://localhost/hospital_website/` in your browser.
5. Register an account and explore the application.

The database and tables are created automatically by the PHP application.

Appointment requests are stored in the MySQL database. Actual email notifications require mail server configuration.
